# Glossário — MPC

## A–C

| Termo | Significado | Observação |
| --- | --- | --- |
| **Argumento** | Premissas que levam a uma conclusão | Pode ser válido ou inválido |
| **Bicondicional (`↔`)** | "Se e somente se" | V quando os valores são iguais |
| **Conclusão** | Proposição final do argumento | Deve decorrer das premissas |
| **Condicional (`→`)** | "Se... então" | Falso só em V → F |
| **Conjunção (`∧`)** | "E" | V só quando ambos são V |
| **Conjunto** | Grupo de elementos com algo em comum | Letra maiúscula |
| **Contingência** | Proposição às vezes V, às vezes F | Oposto de tautologia/contradição |
| **Contradição** | Proposição sempre falsa | Última coluna só F |

## D–L

| Termo | Significado | Observação |
| --- | --- | --- |
| **Diagrama de Venn** | Representação gráfica de conjuntos | Círculos |
| **Diferença (`A - B`)** | Elementos de A que não estão em B | Não é comutativa |
| **Disjunção (`∨`)** | "Ou" | V quando pelo menos um é V |
| **Disjunção exclusiva (XOR)** | "Ou... ou" | V quando os valores diferem |
| **Falácia** | Argumento inválido | Premissas não garantem conclusão |
| **Igualdade de conjuntos** | Mesmos elementos, qualquer ordem | Repetições não importam |
| **Inclusão (`⊂`)** | Todos os elementos de A estão em B | Relação entre conjuntos |
| **Interseção (`∩`)** | Elementos comuns | Simultaneamente nos dois |

## M–R

| Termo | Significado | Observação |
| --- | --- | --- |
| **Negação (`¬`)** | Inverte o valor lógico | `~p` |
| **Par ordenado** | `(a,b)` com ordem | `(a,b) ≠ (b,a)` em geral |
| **Pertinência (`∈`)** | Elemento em conjunto | Diferente de inclusão |
| **Premissa** | Proposição inicial do argumento | P1, P2... |
| **Produto cartesiano** | Todos os pares `(a,b)` de `A × B` | Base da relação binária |
| **Proposição** | Afirmação com valor V ou F | Simples ou composta |

## S–Z

| Termo | Significado | Observação |
| --- | --- | --- |
| **Silogismo** | Argumento válido por forma | Não depende da realidade |
| **Tabela-verdade** | Tabela com todos os valores possíveis | Uma coluna por proposição |
| **Tautologia** | Proposição sempre verdadeira | Última coluna só V |
| **União (`∪`)** | Elementos de A ou de B | Junta os conjuntos |

## Propriedades de relações (complemento externo)

| Propriedade | Definição |
| --- | --- |
| Reflexiva | `∀a, aRa` |
| Simétrica | `aRb → bRa` |
| Antissimétrica | `aRb ∧ bRa → a = b` |
| Transitiva | `aRb ∧ bRc → aRc` |

Essas definições **não estão desenvolvidas no corpus**; aparecem apenas como
pedido na lista (Q4).
