# Glossário — DD

## A–C

| Termo | Significado | Observação |
| --- | --- | --- |
| **Alpha** | Canal de opacidade | 0 a 1 no RGB; vantagem do PNG |
| **Aspect ratio** | Proporção largura:altura | 4:3 (CRT), 16:9 (widescreen) |
| **AVIF** | Formato recente de imagem | Promete ~50% menos que JPEG |
| **Bitmap** | Imagem composta por pixels | Perde qualidade ao ampliar |
| **Brilho/luminosidade** | Quão clara ou escura é a cor | De preto a branco |
| **CMYK** | Ciano, magenta, amarelo e preto | Cor-pigmento, impressão |
| **Complementar** | Cores opostas no círculo | Azul/laranja, vermelho/verde |
| **Compressão** | Redução do tamanho do arquivo | Taxa = final/inicial |
| **Contraste** | Diferença que destaca um elemento | Cor, fonte, tamanho ou peso |

## D–H

| Termo | Significado | Observação |
| --- | --- | --- |
| **DPI** | Dots Per Inch (pontos por polegada) | Impressão; 150, 300, 600, 1200 |
| **Design digital** | Design gráfico para telas | Multimídia estática e dinâmica |
| **Espaço em branco** | "Respiro" entre elementos | Separa seções |
| **Espectro eletromagnético** | Todas as frequências de ondas eletromagnéticas | Do rádio ao gama |
| **Família tipográfica** | Conjunto de fontes coerentes com pesos | Até oito variações |
| **GIF** | Graphic Interchange Format | 1987, 256 cores, 15 fps |
| **HEX** | Código hexadecimal de cor | `#rrggbb` |
| **Hierarquia** | Ordem de leitura por níveis de ênfase | Guia o olhar |
| **Hi-Fi** | Protótipo de alta fidelidade | Próximo do final; alto custo |
| **HSL** | Hue, Saturation, Lightness | Tom em graus; S e L em % |

## I–P

| Termo | Significado | Observação |
| --- | --- | --- |
| **Identidade visual** | Aparência da marca | Logo, cores, tipografia, imagens |
| **Interpolação** | Criação de pixels ao ampliar | O computador "adivinha" |
| **JPEG/JPG** | Joint Photographic Experts Group | Compressão ajustável; perde qualidade |
| **Kerning** | Espaço entre pares específicos de letras | Ajuste manual |
| **Leading** | Entrelinhamento | Espaço entre linhas |
| **Lo-Fi** | Protótipo de baixa fidelidade | Papel, sketch, wireframe |
| **Matiz (hue)** | A própria cor | Dimensão do HSL |
| **MVP** | Minimum Viable Product | Versão mínima que entrega valor |
| **Pantone** | Catálogo cromático | Não é padrão de cor; criado em 1963 |
| **PDF** | Portable Document Format | Imagens, textos e vetores |
| **PNG** | Portable Network Graphics | Canal alpha e boa compressão |
| **PPI** | Pixels Per Inch | Pixels por polegada na imagem |
| **Protótipo** | Modelo para teste | Foco em aprendizado |

## Q–Z

| Termo | Significado | Observação |
| --- | --- | --- |
| **RGB** | Red, Green, Blue | Cor-luz; canais 0–255 |
| **Regra 60-30-10** | 60% dominante, 30% secundária, 10% destaque | Percentuais indicativos |
| **Resolução** | Quantidade de pixels por linha e coluna | 1920×1080 |
| **Saturação** | Intensidade da cor | Sutil ou forte |
| **Serif** | Fonte com traços nas extremidades | Clássica, impressa |
| **Sans serif** | Fonte sem traços | Digital, moderna |
| **SVG** | Scalable Vector Graphics | Vetorial, web |
| **Tetrádica** | Harmonia com dois pares de complementares | Forma retângulo |
| **TIFF** | Tagged Image File Format | Alta qualidade; não comprime |
| **Tipografia** | Arte de compor texto | Além da escolha da fonte |
| **Tracking** | Espaçamento geral entre caracteres | Diferente de kerning |
| **Triádica** | Harmonia em triângulo | Três cores equidistantes |
| **UI** | User Interface | Visual/estética |
| **UX** | User Experience | Funcionalidade/usabilidade |
| **Vetor** | Imagem por fórmulas matemáticas | Escala sem perda |
| **WEBP** | Formato do Google | Compressão + transparência + animação |
| **Wireframe** | Esboço estrutural | Baixa fidelidade |
