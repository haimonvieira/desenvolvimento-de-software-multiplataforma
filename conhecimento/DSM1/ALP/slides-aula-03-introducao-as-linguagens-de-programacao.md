ALGORITMOS
Um algoritmo é um procedimento composto por uma sequência de instruções (descrições de ações) precisas, que a partir de uma entrada (conjunto de dados) produz uma saída (outro conjunto de dados, que é o resultado da execução do algoritmo).

PROGRAMAS
Um programa é um algoritmo escrito em uma linguagem que um computador entende, denominada de linguagem de programação.

## Slide 10

LINGUAGEM DE PROGRAMAÇÃO
Uma linguagem de programação define comandos que podem ser usados para construir programas.
Cada linguagem tem um conjunto específico de comandos e de regras de construção, mas não é preciso conhecer todos os comandos e todas as regras para começar a programar.
