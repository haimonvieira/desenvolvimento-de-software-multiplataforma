- [ ] Tema do projeto definido e explicável.
- [ ] CRUD de `casos` funcionando.
- [ ] MongoDB Atlas conectado.
- [ ] Pelo menos um documento aninhado implementado.
- [ ] Cadastro de usuário funcionando.
- [ ] Login funcionando.
- [ ] JWT funcionando nas rotas protegidas.
- [ ] Argon2id funcionando no cadastro/login.
- [ ] Busca TMDB funcionando.
- [ ] Swagger/OpenAPI atualizado.
- [ ] `/api-docs` funcionando.
- [ ] Requisições organizadas e testadas no Insomnia.
- [ ] README/documentação final coerente com a API real.
- [ ] Protótipo no Figma finalizado.
- [ ] Slides preparados.
- [ ] Apresentação ensaiada para 5 a 7 minutos.
- [ ] Demonstração inclui tema, documentação, Insomnia, Atlas e Figma.
