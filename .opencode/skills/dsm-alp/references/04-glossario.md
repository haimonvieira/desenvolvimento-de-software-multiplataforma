# Glossário — ALP

## A–C

| Termo | Significado | Observação |
| --- | --- | --- |
| **Algoritmo** | Sequência ordenada, finita e não ambígua de instruções para resolver um problema | Definido em `slides-aula-02`, slide 9 |
| **Ambiente de programação** | Conjunto de ferramentas onde o programa é escrito e executado | Slide 14 da aula 03 é só imagem |
| **Argumento** | Duas premissas e uma conclusão | Termo da lógica, `slides-aula-01`, slide 6 |
| **Atribuição (`<-`)** | Comando que guarda um valor na variável | No VisuAlg; em C é `=` |
| **`arquivo`** | Comando do VisuAlg que lê dados de um arquivo-texto | `help-linguagem5` |
| **`aleatorio`** | Comando que substitui a digitação por valores aleatórios | Padrão de 0 a 100 |
| **`Abs`** | Valor absoluto | `help-funcoes` |
| **`Asc`** | Código ASCII do primeiro caractere | `Asc("Brasil")` = 66 |
| **`ate`** | Delimitador final do `repita` e do `para` | Sem acento no VisuAlg |
| **`Carac`** | Caractere correspondente a um código ASCII | `Carac(65)` = "A" |
| **`Caracpnum`** | Converte texto em número | `Caracpnum("9")` = 9 |
| **`caractere`** | Tipo texto (*string*) do VisuAlg | — |
| **Código objeto** | Resultado da compilação | A linkedição gera o executável |
| **Compilador** | Ferramenta que traduz o programa fonte em código objeto | `slides-aula-04`, slide 7 |
| **Compilação** | Primeira fase da geração do executável | Junto com a linkedição, slide 5 |
| **Completo** | Propriedade: todas as ações descritas e únicas | `slides-aula-02`, slide 13 |
| **`Compr`** | Comprimento de uma string | `Compr("Brasil")` = 6 |
| **`Copia`** | Parte de uma string a partir de uma posição | `Copia(c, p, n)` |
| **`cronometro`** | Comando que mede tempo de execução | `cronometro on/off` |

## D–L

| Termo | Significado | Observação |
| --- | --- | --- |
| **`debug`** | Breakpoint condicional | Interrompe se a expressão for verdadeira |
| **Descrição narrativa** | Representação em linguagem natural | Simples, mas ambígua |
| **Determinístico** | Propriedade: o resultado esperado sempre é atingido | `slides-aula-02`, slide 13 |
| **Diagrama de bloco** | Outro nome para fluxograma | — |
| **Diagrama de fluxo** | Outro nome para fluxograma | — |
| **`e`** | Conjunção lógica (AND) | `help-linguagem2` |
| **`eco`** | Comando que imprime os dados de entrada | `eco on/off` |
| **`enquanto`** | Laço que testa a condição **antes** | Zero ou mais execuções |
| **`escolha`** | Seleção múltipla | Com `caso` e `outrocaso` |
| **`escreva`** | Saída sem pular linha | — |
| **`escreval`** | Saída pulando linha | — |
| **`Exp`** | Potência, com base e expoente reais | `Exp(base, expoente)` |
| **Finito** | Propriedade: termina em número limitado de passos | `slides-aula-02`, slide 13 |
| **Fluxograma** | Representação por formas geométricas e setas | Não permite ambiguidade |
| **Função** | Subprograma que **retorna** valor | Usa `retorne` |
| **`fimalgoritmo`** | Encerra o pseudocódigo | O que vem depois é ignorado |
| **`faca`** | Delimitador do início do corpo do laço | `para ... faca` / `enquanto ... faca` |
| **`GraupRad`** | Graus para radianos | `help-funcoes` |
| **`inicio`** | Encerra as declarações e começa os comandos | — |
| **`Int`** | Parte inteira de um número | `Int(1.8)` = 1 |
| **`interrompa`** | Sai imediatamente do laço | `help-linguagem3` |
| **`inteiro`** | Tipo numérico sem casas decimais | — |
| **Linguagem de alto nível** | Linguagem próxima do humano (C, Java, Python) | Precede a de máquina |
| **Linguagem de programação** | Conjunto de comandos e regras para construir programas | `slides-aula-03`, slide 10 |
| **Linguagem intermediária** | Entre a natural e a de programação | Define o Portugol |
| **Linkedição** | Segunda fase: gera o executável a partir do código objeto | — |
| **Linkeditor** | Ferramenta da linkedição | Escrito "Likeeditor" no slide |
| **`limpatela`** | Limpa a tela do VisuAlg | `help-linguagem5` |
| **`leia`** | Entrada de dados do usuário | Abre janela de leitura |
| **`logico`** | Tipo booleano | `VERDADEIRO` ou `FALSO` |
| **Lógica** | Estudo das formas e leis do pensamento | Coerência e racionalidade |

## M–R

| Termo | Significado | Observação |
| --- | --- | --- |
| **`Maiusc` / `Minusc`** | Converte para maiúsculas / minúsculas | `help-funcoes` |
| **Matriz** | Vetor de duas dimensões | Declarada como `vetor [a..b, c..d]` |
| **`MOD` ou `%`** | Resto da divisão inteira | `8 MOD 3` = 2 |
| **`nao`** | Negação lógica (NOT) | Maior precedência entre os lógicos |
| **`Numpcarac`** | Número convertido em texto | — |
| **`outrocaso`** | Caso padrão do `escolha` | Equivale ao `default` |
| **`para`** | Laço contado | Aceita `passo`, inclusive negativo |
| **`passo`** | Incremento do laço `para` | Padrão 1 |
| **`pausa`** | Interrupção incondicional | `help-linguagem5` |
| **`Pi`** | Constante 3.141592 | `help-funcoes` |
| **Portuguol** | Português estruturado / pseudocódigo | Ferramenta: VisuAlg |
| **`Pos`** | Posição de uma substring | `Pos("Brasil", "O melhor do Brasil")` = 13 |
| **Procedimento** | Subprograma que **não** retorna valor | — |
| **Programa** | Algoritmo escrito em linguagem que o computador entende | `slides-aula-03`, slide 8 |
| **Programa fonte** | Programa escrito em linguagem de programação | `slides-aula-01`, slide 19 |
| **Propriedade essencial** | Completo, sem redundância, determinístico, finito | Quatro no total |
| **`Quad`** | Quadrado de um número | `help-funcoes` |
| **Raciocínio** | Processo lógico com ideia, desenvolvimento e conclusão | `slides-aula-01`, slide 10 |
| **`Rand` / `RandI`** | Número real / inteiro aleatório | `RandI(limite)` vai de 0 a limite−1 |
| **`RaizQ`** | Raiz quadrada | — |
| **`real`** | Tipo numérico com casas decimais | Separador decimal é o ponto |
| **Recursão** | Subprograma que chama a si mesmo | Permitida no VisuAlg |
| **`repita`** | Laço que testa a condição **depois** | Uma ou mais execuções |
| **`retorne`** | Devolve o valor da função | — |

## S–Z

| Termo | Significado | Observação |
| --- | --- | --- |
| **Sem redundância** | Propriedade: uma única interpretação possível | `slides-aula-02`, slide 13 |
| **`se` / `senao` / `fimse`** | Condicional | Permite aninhamento |
| **`scanf`** | Leitura de dados em C | `slides-aula-04`, slide 30 |
| **`printf`** | Saída de dados em C | Slide 32 |
| **`timer`** | Execução em câmera lenta | Padrão 500 ms |
| **Teste de mesa** | Simulação manual da execução | **Não há conteúdo** no corpus |
| **Variável global** | Visível em todo o programa | `help-linguagem4` |
| **Variável local** | Existe só durante a chamada do subprograma | `help-linguagem4` |
| **`var`** | Palavra-chave de declaração; em parâmetro, indica referência | Dois usos diferentes |
| **`Verdadeiro` / `Falso`** | Valores lógicos | `FALSO < VERDADEIRO` |
| **Vetor** | Variável composta homogênea de uma dimensão | Índices inteiros |
| **VisuAlg** | Interpretador de Portugol usado na disciplina | Versão 3.0.7 no corpus |
| **`xou`** | Ou exclusivo (XOR) | Verdadeiro se os operandos diferem |
| **`^`** | Potenciação no VisuAlg | Em C não existe; use `pow()` |
| **`\`** | Divisão inteira no VisuAlg | `5 \ 2` = 2 |
