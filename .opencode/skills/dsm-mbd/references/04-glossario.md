# Glossário — MBD

Termos como aparecem no material, com explicação curta.

## A–C

| Termo | Significado | Observação |
| --- | --- | --- |
| **Álgebra relacional** | Conjunto de operações sobre relações | Citada como base do modelo de Codd (aula 01, p. 1), sem detalhamento |
| **Atributo** | Coluna de uma tabela | Também chamado de campo |
| **Banco de dados** | Coleção organizada de dados | Não confundir com SGBD |
| **CA-IDMS** | Versão moderna do IDMS | Exemplo de SGBD em rede (aula 02, p. 1) |
| **Chave estrangeira (FK)** | Coluna que referencia a PK de outra tabela | Cria relacionamento entre tabelas |
| **Chave primária (PK)** | Identificador único de cada registro | Uma por tabela no corpus |
| **Codd, Edgar F.** | Cientista da IBM que propôs o modelo relacional | Artigo de 1970 (aula 01, p. 1) |
| **Componentes do SGBD** | Hardware, software, dados, usuários e procedimentos | Aula 01, p. 2 |

## D–H

| Termo | Significado | Observação |
| --- | --- | --- |
| **DB2** | SGBD relacional da IBM | Citado na popularização dos anos 1980 |
| **Distribuído (SGBD)** | Dados em vários locais | Mais disponibilidade, gestão complexa |
| **Hierárquico (modelo)** | Dados em árvore, um pai e vários filhos | IMS e Windows Registry |
| **IDMS** | Integrated Database Management System | Um dos primeiros SGBDs em rede |

## I–N

| Termo | Significado | Observação |
| --- | --- | --- |
| **Integridade** | Precisão e consistência dos dados | Função do SGBD |
| **Inscrições** | Tabela associativa do exemplo de cursos | Resolve o N:N entre Cursos e Estudantes |
| **Modelo de dados** | Forma de organizar os dados | Rede, hierárquico e relacional no corpus |
| **Modelo em rede** | Grafo com múltiplos pais | Mais flexível, mais complexo |
| **NoSQL** | Bancos não relacionais (documento, grafo, chave-valor) | Citado a partir dos anos 2000 |
| **Nível de abstração** | Físico, lógico e visão | Aula 01, p. 3 |

## R–Z

| Termo | Significado | Observação |
| --- | --- | --- |
| **Registro** | Linha de uma tabela | Também chamado de tupla |
| **Relacional (modelo)** | Dados em tabelas | Base do SQL e dos SGBDs atuais |
| **SGBD** | Sistema de Gerenciamento de Banco de Dados | Software que gerencia o banco |
| **System R** | Protótipo relacional da IBM | Citado junto com o Ingres |
| **Tabela** | Estrutura de linhas e colunas | Estrutura básica do modelo relacional |
| **Visão (nível)** | Como os dados são apresentados ao usuário | Interfaces e relatórios |

## Termos que não estão no corpus

- Entidade, relacionamento e cardinalidade no sentido de **MER formal**.
- Forma normal, dependência funcional, anomalia.
- Esquema, instância, tupla (o corpus usa "registro" e "linha").
- SQL, DDL, DML.

Se o aluno usar esses termos, explique a ponte e diga que a fonte indexada não
os desenvolve.
