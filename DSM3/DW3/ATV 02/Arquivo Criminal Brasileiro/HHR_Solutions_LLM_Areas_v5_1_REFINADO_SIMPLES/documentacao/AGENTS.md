# AGENTS.md - Documentação

Leia também o `../AGENTS.md`, `llms.txt`, `03_DOCUMENTACAO.md` e o contrato global.

## Como ajudar

A documentação deve representar o contrato aprovado e, na versão final, o comportamento real da API.

Ajude com Swagger/OpenAPI, README, Insomnia, métodos, rotas, parâmetros, bodies, schemas, respostas, status e Bearer Auth.

## Regras da área

- Não invente endpoints.
- Não invente status ou respostas.
- Use os tipos definidos pelo Banco.
- Use o comportamento real do Backend para a validação final.
- Backend configura `/api-docs`; Documentação mantém a especificação OpenAPI.
- Divergências entre documentação e API devem ser apontadas antes de serem corrigidas.

## Revisão

Confira método, rota, autenticação, parâmetros, body, schema, respostas, status e exemplos. Valide o fluxo completo no Insomnia.
