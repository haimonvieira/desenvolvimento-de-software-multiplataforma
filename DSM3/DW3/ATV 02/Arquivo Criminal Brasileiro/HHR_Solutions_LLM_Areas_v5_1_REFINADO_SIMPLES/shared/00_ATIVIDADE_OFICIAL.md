# Atividade 02 - Desenvolvendo uma API REST

Fatec Registro  
Curso: DSM  
Disciplina: Desenvolvimento Web III  
Professor: Diego Max

## Requisitos da atividade

1. Desenvolver, em trio, uma API REST com MongoDB sobre um tema de escolha do grupo.
2. Implementar CRUD básico com leitura, cadastro, alteração e exclusão.
3. Hospedar o banco no MongoDB Atlas.
4. Utilizar pelo menos um documento aninhado no modelo de dados.
5. Criar a documentação da API em Markdown no GitHub ou utilizar Swagger.
6. Desenvolver no Figma um protótipo de front-end que represente o consumo da API.
7. Apresentar o trabalho em aula durante 5 a 7 minutos.
8. Na apresentação, explicar o tema, mostrar a documentação, testar a API no Insomnia, mostrar o MongoDB Atlas e o protótipo do Figma.
9. Utilizar slides na apresentação.
