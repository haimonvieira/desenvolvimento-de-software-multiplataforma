# Técnica de Programação 1

## Objeto

Tem atributos e métodos

Metodos sao as acoes que o objeto pode realizer e os atributos sao as caractersticas dele.

## Assinatura do Método

Formado por
- Nome do metodo
- Argumentos (parametros)
- Tipo de resposta (retorno)

Exemplo

public String calcularSalario(int valor)
- Retorna String
- calcularSalario - nome do metodo
- valor - parametro inteiro

Cada atributo tem seu getter e setter
