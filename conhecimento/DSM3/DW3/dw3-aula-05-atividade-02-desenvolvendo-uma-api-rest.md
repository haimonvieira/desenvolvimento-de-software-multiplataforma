Atividade 02 – API Rest e MongoDB (em trio)
01 – Seu trio deve desenvolver uma API Rest com MongoDB referente a algum tema de sua
escolha (exemplos: filmes, animes, músicas, livros, sistemas específicos, etc.)

02 – A API deve ter um CRUD básico que permita a leitura, cadastro, alteração e exclusão de dados.
                                                                                                                       {}
03 – O banco de dados deverá estar hospedado na nuvem (utilizar o serviço do MongoDB Atlas).
Utilizar no mínimo um aninhamento de documentos no modelo de dados.

04 – Crie a documentação da API com a linguagem Markdown (hospedar no Github).
Modelo disponível em: (https://github.com/maxxdiego/17_documentacao_de_api_com_swagger/tree/main/01-
documentacao-manual)

Ou utilize o Swagger para criação da documentação.
Modelo disponível em: (https://github.com/maxxdiego/17_documentacao_de_api_com_swagger)

05 – Por fim, desenvolva um protótipo de front-end no Figma do que seria o consumo desta API.

06 – O trabalho será apresentado em aula. Duração: entre 5 a 7 minutos.

07 – Na apresentação: Explicar o tema; mostrar a documentação da API; testar a API (Insomnia);
mostrar o banco de dados hospedado na nuvem (MongoDB Atlas), mostrar o protótipo do
front-end.

08 – Slides também devem ser usados na apresentação.
